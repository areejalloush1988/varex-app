# VAREX Car Rental — إدارة تأجير السيارات

المجلد الرسمي لنظام تأجير السيارات.

## الوحدات المنفذة

- لوحة التحكم
- السيارات والأسطول
- الحجوزات
- عقود التأجير
- العملاء والسائقون
- فحص واستلام السيارة
- الدفعات والتأمينات
- المخالفات والصيانة
- الموظفون والفروع
- التقارير والإعدادات
- نقطة دفع مستقلة مع النقد وجهاز البطاقة والتحويل والمحفظة
- إيصالات قابلة للطباعة وسجل دفعات مستقل

**الحالة:** النظام جاهز ومربوط بواجهة اختيار الأنظمة. اللون المعتمد: الموف الملكي `#7048A8` مع الأبيض.
