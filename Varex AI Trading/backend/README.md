# Backend integration

هذه الملفات هي نسخة معزولة من كود VAREX AI Trading المنشور داخل موقع VAREX المركزي.

- تعتمد ملفات `lib` على وحدات المصادقة وSupabase relay المشتركة في الموقع المركزي.
- يضاف SQL الموجود في `drizzle/0005_trading_schema.sql` إلى سلسلة ترحيلات D1 في الموقع.
- تبقى مفاتيح وأسرار التشغيل ضمن بيئة الاستضافة ولا تُحفظ في GitHub.
- لا يحتوي هذا المجلد على تنفيذ أوامر مالية حقيقية أو مفاتيح وسيط.
