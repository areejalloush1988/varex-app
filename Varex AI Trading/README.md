# VAREX AI Trading

تطبيق تداول ورقي وربط آمن بحساب Binance Spot داخل مستودع VAREX الرئيسي، منشور على:

`https://app.varexapp.com/trading/`

## المسار العام

- الرابط الرسمي هو `https://app.varexapp.com/trading/` بدون إضافة `www` قبل `app`.
- المسار `/trading` يحوّل تلقائياً إلى `/trading/`.
- عامل التوجيه في موقع VAREX المركزي يربط `/trading/` مباشرةً بملف `trading/index.html` ويخدم ملفات الواجهة من المجلد نفسه.

## الوظائف الحالية

- تسجيل عام مباشر لأي بريد صحيح، مع تأكيد البريد برمز OTP واستعادة كلمة المرور، من دون إضافة مسبقة من حساب المطور.
- حساب المطوّر الأساسي مرتبط بالبريد `areejalloush1988@gmail.com`، ويُنشأ ملفه كمطوّر تلقائياً بعد تأكيد البريد.
- كل حساب جديد يحصل افتراضياً على صلاحية متداول، ويمكن لحساب المطوّر تحديد صلاحية خاصة أو إيقاف حساب.
- تخزين دائم ومعزول حسب `user_id` في D1 لملف المستخدم، الرصيد الورقي، قائمة المراقبة، حدود المخاطر، التحليلات والصفقات.
- أسعار وبيانات شموع حية من Coinbase Exchange للأسواق المدعومة.
- فتح وإغلاق صفقات ورقية بسعر السوق الذي يجلبه الخادم، وليس بسعر يرسله المتصفح.
- ربط Binance Spot مستقل لكل حساب بصلاحية تداول، مع تشفير API Key وSecret Key باستخدام AES-GCM قبل التخزين.
- فحص صلاحيات المفتاح مباشرة من Binance ورفض أي مفتاح يسمح بالسحب أو نقل الأموال أو Margin أو Futures أو Options.
- عرض أرصدة Spot وتفعيل أو إيقاف التداول الحقيقي وضبط حد أعلى لكل أمر.
- اختبار أمر MARKET على Binance قبل إرسال الأمر الحقيقي، ثم حفظ سجل تدقيق للنتيجة.
- تأكيد يدوي مستقل مطلوب لكل صفقة حقيقية؛ لا توجد إعادة تلقائية عند انقطاع الاتصال.
- تبويبات عاملة: لوحة التحكم، فرص الذكاء، الصفقات، مركز المخاطر، حساب التداول، قائمة المراقبة، التقارير، الحسابات والإعدادات.
- تقارير محسوبة من سجل الحساب مع تصدير CSV.

## حركة الأموال

- الإيداع يتم داخل حساب Binance، وليس داخل VAREX.
- السحب يتم داخل حساب Binance، وليس داخل VAREX.
- VAREX لا يحتفظ بالأموال ولا يوفر عنوان إيداع أو سحب.
- VAREX يرسل أوامر Spot فقط بعد تأكيد يدوي واضح.

## حدود الأمان

التداول الورقي هو الوضع الافتراضي ولكل مستخدم رصيد وسجل مستقلان. التداول الحقيقي متاح لكل حساب بصلاحية تداول بعد ربط مفتاحه الخاص بصلاحية Reading وSpot Trading، مع تعطيل السحب وكل صلاحيات نقل الأموال. التحليل احتمالي وليس ضماناً للربح أو توصية استثمارية، وخسارة التداول تبقى ممكنة.

## بنية المجلد

- `index.html`, `styles.css`, `app.js`: واجهة التطبيق العربية المتجاوبة.
- `backend/lib`: المصادقة، الصلاحيات، التخزين، محرك التحليل وبيانات السوق.
- `backend/lib/trading-broker.ts`: التشفير، توقيع HMAC، فحص صلاحيات Binance وتنفيذ أوامر Spot.
- `backend/app/api`: مسارات API الخاصة بالتداول وتأكيد البريد.
- `backend/drizzle`: ترحيلات D1 للحسابات وحالة التداول وربط الوسيط وسجل الأوامر الحقيقية.
- `tests`: فحوص سلامة مخصصة للتطبيق.

النسخة المنشورة تعمل ضمن موقع VAREX المركزي، لذلك تستخدم نظام المصادقة وD1 المشتركين في الموقع مع عزل جداول وواجهات AI Trading.
