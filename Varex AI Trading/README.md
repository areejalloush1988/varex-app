# VAREX AI Trading

تطبيق تداول تجريبي ضمن مستودع VAREX الرئيسي.

- الرابط المنشور: `https://app.varexapp.com/trading/`
- مجلد المصدر: `Varex AI Trading`
- مجلد المسار العام: `trading`
- الواجهة: عربية RTL ومتجاوبة مع الكمبيوتر والموبايل.
- الوضع الحالي: Paper Trading ببيانات وأسعار محاكاة فقط.

## الملفات

- `index.html`: واجهة التطبيق.
- `styles.css`: تصميم VAREX الكحلي والأصفر والتجاوب.
- `app.js`: تبديل الأسواق، التحليل التجريبي، إدارة المخاطر، والصفقات التجريبية.
- `favicon.svg`: أيقونة التطبيق.

> لا ينفذ التطبيق أوامر مالية حقيقية، ولا يحتوي على مفاتيح API أو بيانات دخول.
