# VAREX AI Trading

تطبيق تداول ورقي فعلي داخل مستودع VAREX الرئيسي، منشور على:

`https://app.varexapp.com/trading/`

## المسار العام

- الرابط الرسمي هو `https://app.varexapp.com/trading/` بدون إضافة `www` قبل `app`.
- المسار `/trading` يحوّل تلقائياً إلى `/trading/`.
- عامل التوجيه في موقع VAREX المركزي يربط `/trading/` مباشرةً بملف `trading/index.html` ويخدم ملفات الواجهة من المجلد نفسه.

## الوظائف الحالية

- تسجيل دخول وإنشاء حساب مع تأكيد البريد برمز OTP واستعادة كلمة المرور.
- حساب المطوّر الأساسي مرتبط بالبريد `areejalloush1988@gmail.com`، ويُنشأ ملفه كمطوّر تلقائياً بعد تأكيد البريد.
- إضافة مستخدمين حقيقيين وتحديد صلاحية كل مستخدم: متداول أو مشاهِد، مع التفعيل والإيقاف.
- تخزين دائم في D1 لملف المستخدم، قائمة المراقبة، حدود المخاطر، التحليلات والصفقات الورقية.
- أسعار وبيانات شموع حية من Coinbase Exchange للأسواق المدعومة.
- فتح وإغلاق صفقات ورقية بسعر السوق الذي يجلبه الخادم، وليس بسعر يرسله المتصفح.
- تبويبات عاملة: لوحة التحكم، فرص الذكاء، الصفقات، مركز المخاطر، قائمة المراقبة، التقارير، المستخدمون والإعدادات.
- تقارير محسوبة من سجل الحساب مع تصدير CSV.

## حدود الأمان

الوضع الحالي هو **Paper Trading** فقط. لا يرسل التطبيق أوامر مالية ولا يتصل بحساب وسيط، لأن التداول الحقيقي يحتاج اختيار وسيط معتمد ومفاتيح API وصلاحيات واضحة واختبارات امتثال ومخاطر. التحليل احتمالي وليس ضماناً للربح أو توصية استثمارية.

## بنية المجلد

- `index.html`, `styles.css`, `app.js`: واجهة التطبيق العربية المتجاوبة.
- `backend/lib`: المصادقة، الصلاحيات، التخزين، محرك التحليل وبيانات السوق.
- `backend/app/api`: مسارات API الخاصة بالتداول وتأكيد البريد.
- `backend/drizzle`: ترحيل جداول D1 الخاصة بالتطبيق.
- `tests`: فحوص سلامة مخصصة للتطبيق.

النسخة المنشورة تعمل ضمن موقع VAREX المركزي، لذلك تستخدم نظام المصادقة وD1 المشتركين في الموقع مع عزل جداول وواجهات AI Trading.
