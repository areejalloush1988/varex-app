# Tablet and iPad

- أجهزة Android Tablet تستخدم مشروع `mobile/android` نفسه؛ النظام يدعم الشاشات الكبيرة والوضعين الأفقي والعمودي.
- أجهزة iPad تستخدم مشروع `mobile/ios` نفسه؛ هدف Xcode يدعم عائلة iPhone وiPad.
- يمكن تثبيت نسخة الويب مباشرة من Chrome أو Safari كاختصار/تطبيق مستقل من رابط النظام.
