# VAREX Women's Salon

المشروع المستقل الكامل لنظام **VAREX لإدارة الصالون النسائي**، بالهوية التوتية المعتمدة وشعار VAREX الرسمي.

## محتويات المشروع

- `web-source/` — المصدر الكامل للنسخة الحالية المنشورة.
- `mobile/` — مشروع Capacitor مستقل لـ Android وAndroid Tablet وiPhone وiPad.
- `windows/` — مشروع Electron مستقل لإنتاج مثبت Windows ونسخة Portable.
- `tablet/` — إعدادات الشاشات الكبيرة وملف تثبيت PWA للتابلت.

## المنصات الجاهزة

| المنصة | مكان المشروع | الناتج عند البناء |
|---|---|---|
| Android Phone | `mobile/android` | APK / AAB |
| Android Tablet | `mobile/android` | APK / AAB مع دعم الشاشات الكبيرة |

| iPad | `mobile/ios` | نفس مشروع iOS مع دعم iPad |

| Tablet PWA | `tablet` | تثبيت مباشر من المتصفح |

## ملاحظة التوقيع والنشر

المصادر ومشاريع البناء جاهزة. إصدار متجر Google Play يحتاج مفتاح توقيع Android، وإصدار App Store يحتاج حساب Apple Developer وشهادة Provisioning، وإصدار Windows الموقّع يحتاج شهادة Code Signing. لا تُحفظ أي مفاتيح أو شهادات داخل المستودع.
