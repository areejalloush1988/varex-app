# VAREX Restaurant public demo

This directory contains the official public portfolio demo for the VAREX Restaurant Management System.

- Public entry: `https://app.varexapp.com/restaurant/demo.html`
- Direct entry: `https://app.varexapp.com/restaurant/open-v7.html?preview=1&type=restaurant&lang=ar`
- Demo mode uses temporary seeded data and does not expose authentication, billing, or private account data.
