# VAREX AI Android

تطبيق Android أصلي يعمل كجسر آمن بين موظف VAREX AI وبين إمكانيات هاتف المالك. التطبيق ليس WebView ولا نسخة PWA؛ الصلاحيات تُمنح من Android نفسه وتبقى خاضعة أيضاً لوضع الصلاحية المحدد لكل موظف في لوحة VAREX AI.

## النسخة الأولى

- تسجيل الدخول بنفس حساب VAREX AI وحفظ الجلسة مشفرة عبر Android Keystore.
- ربط الهاتف بمساحة العمل وإظهار حالته في مركز الصلاحيات.
- خدمة أمامية مرئية تبقي الجسر متصلاً عندما يفعّلها المالك.
- جهات الاتصال: عرض، بحث، إضافة، تعديل، وحذف.
- التقويم: عرض، إنشاء، تعديل، إلغاء، وحذف.
- المنبّه: إنشاء وتشغيل وتعديل أو إيقاف عبر واجهات تطبيق الساعة القياسية.
- الهاتف: البحث عن رقم وبدء مكالمة عادية من شريحة الهاتف.
- الإعدادات: عرض الحالة، فتح صفحات الإعداد، وتغيير السطوع والدوران ومهلة الشاشة عند منح السماح الخاص.
- إعادة النتيجة إلى سجل التنفيذ مع سبب الفشل الحقيقي.
- عدم تكرار أي أمر تلقائياً إذا انقطع الاتصال بعد بدء التنفيذ، لتجنب تكرار مكالمة أو حذف أو إضافة.

## بناء APK

يتطلب Android SDK 36 وJava 17 وGradle 8.13:

```bash
gradle -p 11-VAREX-AI-Employee/android lintDebug assembleDebug
```

يظهر الملف في:

```text
11-VAREX-AI-Employee/android/app/build/outputs/apk/debug/app-debug.apk
```

النسخة التجريبية موقعة بمفتاح Android التجريبي. قبل النشر للعملاء يجب إنشاء مفتاح إصدار خاص بـVAREX وحفظه خارج المستودع.

## أمثلة أوامر

```text
أضف جهة اتصال: أبو كرم | +971501234567
ابحث في جهات الاتصال عن أبو كرم
أضف موعد: اجتماع العميل | 2026-09-17 14:00
اضبط منبّه الساعة 07:30 | الدوام
اتصل بأبو كرم
غيّر سطوع إعدادات الهاتف إلى 60
```

لا يستخدم التطبيق Accessibility Service ولا يحاول تجاوز حماية Android، ولا يستطيع التحدث بصوت آلي داخل مكالمة الشريحة العادية.
