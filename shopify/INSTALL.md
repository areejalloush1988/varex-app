# ربط متجر VAREX بصفحات الأنظمة

يوضع السطر التالي مرة واحدة قبل `</head>` في ملف تخطيط قالب Shopify:

```liquid
<script defer src="https://app.varexapp.com/shopify/varex-plan-links.js"></script>
```

يحوّل الملف روابط المنتجات الاثني عشر وأزرار «اختر الباقة» إلى صفحة النظام المناسبة، ثم تربط أزرار الباقات مباشرة بمتغير الاشتراك الصحيح في سلة Shopify.
