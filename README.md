# VAREX — نظام إدارة الصيدليات

نظام صيدليات مستقل بهوية VAREX واللون النيلي المعتمد، مصمم بواجهة مختلفة عن أنظمة VAREX الأخرى.

## الصفحات

- تسجيل الدخول، إنشاء حساب، التحقق من البريد، نسيت كلمة المرور وإعادة تعيينها.
- لوحة التحكم ونقطة البيع.
- الأدوية والمخزون والتشغيلات وتواريخ الصلاحية.
- المشتريات والموردون والعملاء والوصفات الطبية.
- المصروفات والموظفون وضريبة القيمة المضافة VAT والتقارير والإعدادات.

## وظائف الواجهة

- صوت نقر يمكن تشغيله وإيقافه.
- وضع ملء الشاشة.
- أحجام عرض: 100%، 90%، 80%، 70%، 60%، 50%.
- تصميم قمرة صيدلية مستقل: وحدات التشغيل في شريط علوي، أدوات الإدارة في مسار يساري، والتحكم أسفل الشاشة.
- شعار VAREX نفسه من المرجع المعتمد: حرف V وكتابات VAREX وBUSINESS MANAGEMENT SYSTEM بالأبيض، مع اللون النيلي #4E4B9A للأيقونة والواجهة.
- خطوط وأيقونات أكبر وأثقل لتكون القراءة واضحة في العرض الكامل وعلى الشاشات الصغيرة.
- شريط تحكم علوي يضم اسم المدير والتكبير والتصغير واللغة والمظهر والصوت وملء الشاشة وتبديل المستخدم والخروج.
- مظهر فاتح وداكن، مع بطاقات التحكم باللون النيلي المعتمد.
- تقرير VAT للمخرجات والمدخلات وصافي الضريبة مع التصدير والطباعة.
- تصميم متجاوب مع التابلت والهاتف والكمبيوتر.
- حفظ بيانات التشغيل محلياً في المتصفح إلى حين ربط جداول الصيدليات بقاعدة البيانات.

## التشغيل

افتح `index.html` من خادم ويب، أو افتح مسار المجلد من GitHub Pages.

للمعاينة دون حساب، استخدم زر **الدخول التجريبي** في صفحة تسجيل الدخول.
