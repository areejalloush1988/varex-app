## حالة المشروع

- الإصدار الحالي: **VAREX 1.1.0**
- النظام التشغيلي الحالي: **الكاشير والحسابات**
- النظام العقاري: **ملفاته داخل مجلد إدارة العقارات**
- تأجير السيارات وكار ليفت والصالونات والمطاعم: **ملفات كل نظام داخل مجلده المخصص**
- مكتبة فاريكس: **ملفاتها معزولة داخل مجلد `10-مكتبة-فاريكس`**
- VAREX AI Employee: **ملفاته معزولة داخل مجلد `11-VAREX-AI-Employee` ومساره العام `/ai`**
- VAREX AI Trading: **ملفاته معزولة داخل مجلد `Varex AI Trading` ومساره العام `/trading`**
- VAREX Call: **ملفاته معزولة داخل مجلد `12-VAREX-Call` ومساره العام `/call`**

> جميع الصفحات والملفات الخاصة بكل نظام موجودة داخل مجلده المخصص. بقيت في جذر المستودع فقط صفحات الدخول واختيار النظام وملفات التشغيل المشتركة اللازمة للموقع وتطبيق Android وGitHub Pages.
