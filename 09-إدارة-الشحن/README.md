# VAREX — إدارة الشحن

المصدر الرسمي لتطبيق **VAREX Shipping Management** داخل مستودع VAREX. هذا المشروع مستقل عن تطبيقات الكاشير والصالونات وتأجير السيارات والمطاعم، ولا يشارك معها ملفات الواجهة أو بيانات التشغيل.

## الوظائف الحالية

- مركز العمليات، طلبات الاستلام، الشحنات والتتبّع.
- الأسطول، المستودعات، السائقون والعملاء.
- الحسابات، الموظفون، الإقرار الضريبي والتخليص الجمركي.
- التقارير والإعدادات و30 مظهرًا و20 لغة.
- تسجيل الدخول وإنشاء منشأة وتسجيل الخروج.
- تأكيد البريد واستعادة كلمة المرور بواسطة OTP من 6 أرقام.
- تأخير مرئي آمن لمدة 2–3 ثوانٍ لعمليات الدخول والخروج والحفظ.

## فصل المصدر والبيانات

- كود التطبيق وشعاره محفوظان في مجلد GitHub المستقل `09-إدارة-الشحن`.
- حسابات الدخول والـOTP مرتبطة بمشروع Supabase المركزي **VAREX** المعتمد لبقية المنظومة.
- كل منشأة شحن تحمل النوع `shipping`، وتُفصل سجلاتها بواسطة هوية المنشأة وسياسات الوصول.
- GitHub لا يحتوي كلمات مرور أو رموز OTP أو مفاتيح سرية.
- كل الأسماء والأرقام والشحنات والقيم المالية المعبأة مسبقًا بيانات عرض خيالية موسومة بكلمة `تجريبي`، وليست بيانات عملاء حقيقية.
- تفضيلات الجهاز غير الحساسة فقط، مثل اللون واللغة، تُحفظ محليًا في المتصفح.

## الملفات الأساسية

- `app/page.tsx`: واجهة النظام وتدفقات الحساب.
- `app/globals.css`: التصميم المتجاوب ومظهر الدخول والنظام.
- `lib/varex-shipping-auth.ts`: الربط الآمن مع حسابات VAREX والـOTP.
- `public/varex-shipping-logo.svg`: الشعار المعتمد.
- `public/varex-shipping-logo.png`: نسخة الشعار النقطية المعتمدة.

## التشغيل والفحص

يتطلب Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

الفحوص المتاحة:

```bash
npm run lint
npm run build
```

لا تنقل ملفات هذا المجلد إلى مجلد تطبيق آخر، ولا تضع بيانات العملاء أو كلمات المرور داخل المستودع.
