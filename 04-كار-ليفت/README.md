# VAREX Car Lift — كار ليفت

المجلد الرسمي لنظام إدارة رحلات كار ليفت والنقل المشترك.

## الوحدات المنفذة

- لوحة التحكم
- السائقون
- الركاب والعملاء
- الرحلات والمسارات
- المركبات
- الاشتراكات والحجوزات
- الحضور والمواعيد
- الدفعات والمحافظ
- التنبيهات والتقارير
- الإعدادات والصلاحيات
- مركز تشغيل مباشر لتوجيه السائقين
- نقطة دفع مستقلة مع النقد وجهاز البطاقة والمحفظة والتحويل
- إيصالات قابلة للطباعة وسجل دفعات مستقل

**الحالة:** نظام VAREX Taxi & Car Lift جاهز ومربوط بواجهة اختيار الأنظمة. اللون المعتمد: الأصفر الذهبي `#D9A400` مع الكحلي والأبيض.
