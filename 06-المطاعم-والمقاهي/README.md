# VAREX للمطاعم والمقاهي

نظامان متخصصان ضمن بوابة واحدة، مع اختيار نوع النشاط لمرة واحدة ثم فتح النظام المختار مباشرةً:

- المطاعم: هوية برتقالية `#E56F2D`.
- المقاهي: هوية بني موكا `#8A5A44`.
- تصميم نهاري ثابت بدون مبدّل وضع ليلي/نهاري.
- بيانات مستقلة لكل نوع نشاط.
