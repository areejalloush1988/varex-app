# VAREX للمطاعم والمقاهي

النسخة المستقلة الأحدث من نظام VAREX لإدارة المطاعم، محفوظة بالكامل داخل هذا المجلد.

- المطاعم: برتقالي طوبي `#E56F2D`، مطابق للون أيقونة المطاعم في موقع VAREX.
- المقاهي: بني موكا `#8A5A44`، مطابق للجزء الثاني من أيقونة المطاعم والمقاهي.
- التشغيل الرئيسي: [index.html](./index.html).
- اختيار المطاعم أو المقاهي: [dining.html](./dining.html).
- لوحة المطاعم: [restaurant.html](./restaurant.html).
- لوحة المقاهي: [cafe.html](./cafe.html).

## الأقسام

لوحة التحكم، الكاشير والطلبات، إدارة الطلبات، الطاولات والحجوزات، المنيو والوصفات، شاشة المطبخ، العملاء والولاء، الموظفون والورديات، المكونات والمخزون، الموردون والمشتريات، التقارير والتحليلات، الإعدادات، والاشتراك والترخيص.

## ملاحظات النسخة

- تشغيل مباشر بدون حلقة تسجيل دخول.
- تثبيت الأيقونات ومنع اهتزاز الشاشة.
- تحكم بحجم الشاشة مناسب للتابلت.
- ملفات التطبيق وروابطه داخل هذا المجلد، بدون إضافة ملفات خاصة بالمطاعم إلى جذر المستودع.
- أزيلت النسخ القديمة والمكررة، واعتمد ملف التشغيل الأحدث `varex-app-v2.js` فقط.
- بيانات المطاعم والمقاهي مستقلة على الجهاز.

الإصدار: VAREX 1.1.0.
