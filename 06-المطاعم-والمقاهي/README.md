# VAREX للمطاعم والمقاهي

نظامان متخصصان ضمن بوابة واحدة، مع اختيار نوع النشاط لمرة واحدة ثم فتح النظام المختار مباشرةً:

- المطاعم: هوية برتقالية `#E56F2D`.
- المقاهي: هوية بني موكا `#8A5A44`.
- تصميم نهاري ثابت بدون مبدّل وضع ليلي/نهاري.
- بيانات مستقلة لكل نوع نشاط.

## الملفات الرئيسية

- `dining.html`: اختيار المطاعم أو المقاهي.
- `restaurant.html`: لوحة تحكم المطاعم.
- `cafe.html`: لوحة تحكم المقاهي.
- `dining.js`: منطق النظام والبيانات والعمليات.
- `dining.css`: التصميم المشترك والهوية اللونية.

## الأقسام

لوحة التحكم، الكاشير والطلبات، إدارة الطلبات، الطاولات والحجوزات، المنيو والوصفات، شاشة المطبخ، العملاء والولاء، الموظفون والورديات، المكونات والمخزون، الموردون والمشتريات، التقارير والتحليلات، والإعدادات.

الحالة الحالية: جاهز ضمن VAREX 1.1.0.
